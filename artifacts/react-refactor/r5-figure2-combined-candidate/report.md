# Figure2 双人物单媒体候选验证

状态：5 MB 以内候选、正反播放、定向性能与浏览器视觉验收完成；尚未替换 production 资产或场景实现。

## 推荐候选

`figure2-pair-universal-792x660-bidirectional-crf33-g13-seam-exact.candidate.webm`

- 单一响应式资产，不区分 mobile / desktop。
- 画布 792×660，保持原 1280×1066 构图比例与 80 px 中缝的缩放关系。
- 前 78 帧正序，后 78 帧倒序；156 帧、30 fps、5.2 s。
- 正向播放 0–2.6 s，反向播放 2.6–5.2 s；两个方向都使用浏览器原生正向播放，不逐帧 seek。
- VP9 WebM、alpha、CRF 33、GOP 13；最长 GOP 0.433 s。
- 2.567 s 与 2.600 s 都是关键帧，正序末帧和倒序首帧解码后的 RGBA 完全一致。
- 大小 4,940,268 B（4.71 MiB）；SHA-256：`a87db407fd39f6977aa0b663ffd16e54929259e6651728997f7c072a33ffaa80`。

## 压缩结果

| 资产组 | 大小 | 相对最初通用候选 |
| --- | ---: | ---: |
| 最初通用双向 1280×1066 | 17,704,079 B | 基准 |
| 上轮 seam-exact 1280×1066 | 14,986,646 B | -15.35% |
| 当前 production 四条正反文件合计 | 15,926,811 B | -10.04% |
| 推荐 792×660 seam-exact | 4,940,268 B | -72.09% |

单靠提高 CRF 无法安全降到 5 MB：1280×1066 的透明线稿在 CRF 30 时 alpha 已明显损失。因此最终保留全部 156 个作者方向帧、原生双向播放和精确 seam，主要通过把媒体分辨率降到仍覆盖实际 CSS 呈现尺寸的 792×660 来缩小体积。

## 媒体质量

先把作者左右源文件按同一 Lanczos 路径缩放至目标分辨率，再比较完整 78 帧时序：

| 区间 | Alpha SSIM | 暖纸合成 SSIM |
| --- | ---: | ---: |
| 正序 0–2.6 s | 0.988557 | 0.988303 |
| 倒序 2.6–5.2 s | 0.987890 | 0.987898 |

正序末帧与倒序首帧的 alpha、暖纸合成和完整 RGBA 均逐像素一致。与 1280×1066 候选相比，人物极细纹理存在轻微软化，但在当前桌面和移动端实际 CSS 尺寸下没有出现轮廓破损、透明孔洞、黑边或 matte。

## 正反播放与性能

只运行最终 4.94 MB 候选的一次 390×844 Chromium 定向测量，没有运行 Playwright 测试套件或浏览器矩阵。renderer 为 SwiftShader，结果用于相对方案判断。

| 路径 | rAF p50 / p95 | >25 ms | 解码 / dropped | 浏览器进程 CPU | CPU / wall |
| --- | ---: | ---: | ---: | ---: | ---: |
| 正序 0–2.6 s，原生播放 | 16.7 / 33.4 ms | 13.6% | 87 / 1 | 3.10 s | 1.174 |
| 倒序段 2.6–5.2 s，原生播放 | 16.7 / 33.4 ms | 12.9% | 83 / 1 | 3.05 s | 1.162 |

两个方向均为 `playbackRate=1`，没有触发 timeline fallback；正序落在 2.600 s，倒序落在 5.180 s。相较 14.99 MB 版本，正序 CPU 从 3.82 s 降至 3.10 s，倒序从 3.60 s 降至 3.05 s。

## 浏览器视觉验收

同一候选分别在 390×844 和 1440×900 检查 p=0、p≈0.5、p=1：

- 人物间距、居中关系、尺寸和落脚点没有改变。
- 透明边缘、飘带、衣袖和头冠没有新增黑边、白底、matte 或透明孔洞。
- 正反端点布局一致，重复端点帧 RGBA 完全一致，没有编码 seam 闪动。
- 相对 1280×1066 版本只存在预期的细节轻微软化；在实际显示尺寸下可接受。

证据：`under5mb-mobile-p0.png`、`under5mb-mobile-p50.png`、`under5mb-mobile-p100.png`、`under5mb-desktop-p0.png`、`under5mb-desktop-p50.png`、`under5mb-desktop-p100.png`。
