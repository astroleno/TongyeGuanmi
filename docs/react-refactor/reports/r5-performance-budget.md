## CI Interpretation

Hardware thresholds are desktop 20 ms/mobile 34 ms and <1% long frames. Linux CI may expose SwiftShader/software rendering; the test reports that renderer explicitly and uses a separate non-release diagnostic ceiling so software GPU noise does not masquerade as target-device performance. The candidate decision uses the hardware M4 measurements above; any target device failing the hardware gates requires a separate HITL exception.
