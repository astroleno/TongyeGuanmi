## 目标与交付

本轮在不删减原有 16 章、动画、媒体和阅读内容的前提下，补齐加载等待、公开联系和站点识别体验：

- 冷启动 Loader 从 5.38 秒缩短到 3.18 秒，并在静态首屏和 React 接管后持续显示品牌、状态与进度；Hero 入场从 2.7 秒缩短到 1.8 秒，标题和副标题更早完成。
- Contact、手机 Contact、构建时静态正文、服务页、问答页、`llms.txt` 和结构化数据统一使用 `aitoshuu@gmail.com`；主要联系操作仍使用带主题的 `mailto:`，页面同时明文显示邮箱。
- 手机菜单展开后使用完整、不透底的视口层，“直接阅读”保持高对比度；Pattern 桌面标题锁定短语换行，不再让逗号落在新行首。
- 新增独立 1200 × 630、96,068 B 的社交分享图，以及 ICO、Apple Touch、192/512 图标和 Web App Manifest；首页改为 `public, max-age=0, must-revalidate`，机器可读资源和图标纳入发布烟测。
- Hero 背景在来源权威不变的前提下由 437,030 B 压到 289,038 B，SSIM 为 0.961994。Figure2 的 4.9 MB VP9 Alpha 主资源保持不变，避免破坏已经冻结的画质与透明度合同。
- 媒体恢复测试同时覆盖 WebM 与 MP4，并使用与正式 20 秒准备预算一致的等待窗口。

主体实现提交为 `cc6ada617992b1108df77474b7f63c004514cd04`。正式 CDN 构建揭示候选 v52 比手机 JS 硬上限多 339 B；`a4ba76c` 将 Loader 的可见品牌和进度改为等价的关键 CSS 绘制，在不放宽预算、不改变画面和可访问名称的情况下恢复发布资格。v52 保持为未发布的不可变候选，v53 才是正式身份。

## 已知边界

`aitoshuu@gmail.com` 是本轮按约定使用的占位联系地址；替换为长期商务渠道时仍需同步 Contact、静态正文、内容页、`llms.txt`、结构化数据和相应回归测试。

浏览器模拟、WebKit 引擎检查和本机内存认证不冒充真机 Safari、Chrome 或微信验收。真实手机上的空白帧比例、帧率、发热和微信内核兼容仍需物理设备证据。当前手机 JS 硬预算只余 1 B，后续增加运行时代码必须先回收体积并重新通过正式 CDN 构建门禁。
