像琉璃在页面里慢慢成形

这套组件把 Shader Park 参考里的体积 blob 翻译成纯 HTML/CSS：低频乳白、淡粉、鼠尾草绿与浅琥珀色在内部混合，边缘用透明密度场自然变薄，而不是白色描边或标准玻璃胶囊。

最小使用方式

引入 blob-glass.css，再给元素添加 .blob-glass 与尺寸修饰类：.blob-glass--nav、.blob-glass--card 或 .blob-glass--button。材质的颜色、密度、边缘厚薄、背景模糊与气泡杂质都可以通过 CSS 自定义属性覆盖。
