渐进式模糊
演示

向下滚动，观察导航栏如何从顶部产生 iOS 26 风格的 Liquid Glass 羽化模糊效果。

组件原理

使用 7 层 backdrop-filter 叠加，每层通过 CSS mask-image 控制纵向可见区间。越靠近顶部，blur 值越大，形成从强到弱的自然羽化过渡。

零依赖

纯 CSS 实现，不需要 React、Vue 或任何框架。通过给 .site-nav 添加 .ios26-blur-enabled 类即可启用。不修改任何现有代码。

自动降级

在不支持 backdrop-filter 的浏览器中，组件通过 @supports 查询自动隐藏，回退到你原有的渐变遮罩效果。

性能优化

移动端自动减少模糊层数（隐藏第 6、7 层），降低 GPU 开销。同时支持 prefers-reduced-motion 媒体查询。

继续向下滚动…

导航栏会始终保持渐进模糊效果。你可以随时用右下角按钮切换对比原有渐变遮罩和新的渐进模糊。

与现有系统的兼容性

你的 lost-wax-glass-nav.css 中已有的 ::before 渐变遮罩在启用 ios26-blur-enabled 后会自动隐藏（display: none），两者不会冲突。

深色 / 亮色主题

组件包含 .ios26-progressive-blur__tint 层，会根据 .is-light 类自动切换 tint 颜色，适配你的 data-tone="light" 逻辑。
